# The native compiler's grammar

`grammar.json` is the grammar of the packed LL(1) parser of `BASIE.COM`.
The language specification remains authoritative for the language's
meaning; this file makes the native compiler's syntax executable.
`tools/llgen.ts` generates `../GRAMMAR.ASM` from it (`deno task grammar`),
and `tests/llgen_test.ts` checks that the tables are current and that the
grammar is LL(1). Edit the grammar, never the tables.

The file holds:

- `productions`: each a left side and its right side of grammar symbols:
  nonterminals, tokens (`Token...`), semantic actions (`a:Name`) and
  islands (`x:Name`), where a hand-written parser takes over;
- `externals`: the tokens that may begin each island, its FIRST set;
- `terminals`: the token kind (`TK_` in `STATE.ASM`) of each token;
- `diagnostics` and `diagnosticCodes`: the diagnostic each nonterminal
  raises when no production is predicted, and its `DG_` code;
- `actions`: the routine of each action and island, in ordinal order;
- `equates`: names other modules use for a row (`GR_STMT`) or an action
  ordinal (`GR_EXIT`).

Nonterminals are numbered in order of their first production; productions
by their bodies, equal bodies sharing a number (every empty production is
one); actions in the order of `actions`. The generator splits the bodies
in two directories when they pass 255 bytes, so that every offset is a
byte.

Expressions, name-led statements, and type-directed aggregate initializers are
deliberate external islands. They require precedence or symbol and type
information that token lookahead alone cannot supply.

The packed statement grammar keeps failure consumption immediate: `else fail`
propagates a direct failable call, while same-line `handle NAME` opens its local
handler body. Boolean `or` remains entirely inside the expression island.

The grammar began as Nucleus's (`stage7-grammar.json`, from which
`GRAMMAR.ASM` was first generated by a generator that wrote AZM). From
the conversion to ATOM (step 65.0) until step 67 the tables were edited
by hand and the JSON kept in step; at step 67 the generator was written
for ATOM and reproduced the hand-kept tables byte for byte before the
grammar changed.
